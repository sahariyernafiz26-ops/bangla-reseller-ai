# বাংলা রিসেল এআই (Bangla Resell AI) 🛍️
### মোবাইল ফ্রেন্ডলি F-Commerce সহকারী, ভয়েস ও অর্ডার হিসাব অ্যাপ

এই প্রজেক্টটি অ্যান্ড্রয়েড ফোনে ব্যবহার ও **Android APK তৈরি করার জন্য ১০০% উপযুক্ত ও প্রস্তুত**।

---

## 📱 কম্পিউটার ছাড়া শুধু মোবাইল দিয়ে APK পাওয়ার উপায়:

### ১. PWABuilder দিয়ে ফোন থেকেই সরাসরি APK ডাউনলোড (ফ্রি)
- আপনার ফোনের ব্রাউজার থেকে **[pwabuilder.com](https://www.pwabuilder.com/)** সাইটে যান।
- আপনার অ্যাপের ডেভেলপমেন্ট বা শেয়ার্ড লিংকটি পেস্ট করুন।
- **Android APK** সিলেক্ট করে ডাউনলোড বাটনে চাপ দিলেই মাইক্রোসফটের ক্লাউড সার্ভার ১ মিনিটে আপনার ফোনের জন্য আসল `.apk` ফাইল বানিয়ে ডাউনলোড করে দেবে।

### ২. সরাসরি ফোনে ইনস্টল (WebAPK)
- আপনার ফোনের **Google Chrome** ব্রাউজারে অ্যাপটির লিংক খুলুন।
- ওপরের **`📲 ইনস্টল/APK`** বাটনে চাপ দিয়ে **'Install app'** বা **'Add to Home screen'** নির্বাচন করুন।
- এটি সরাসরি আপনার ফোনের অ্যাপ মেন্যু ও হোমস্ক্রিনে আসল অ্যাপের মতো ইনস্টল হয়ে যাবে।

### ৩. GitHub Actions (ক্লাউডে সম্পূর্ণ অটোমেটিক APK বিল্ড)
- প্রজেক্টের ভেতরে `.github/workflows/android-build.yml` ফাইল যুক্ত আছে। GitHub-এ আপলোড করলেই ক্লাউডে স্বয়ংক্রিয়ভাবে `app-debug.apk` তৈরি হয়ে যাবে।

---

## 💻 কম্পিউটারে Android Studio দিয়ে APK বিল্ড (ঐচ্ছিক):
- Android Studio-তে `android` ফোল্ডার ওপেন করে `Build > Build APK` চাপলে `app-debug.apk` তৈরি হয়।
